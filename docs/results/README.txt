================================================================================
SMART CANTEEN - EVALUATION & EXPERIMENTAL RESULTS
================================================================================

This directory contains experimental results, evaluation plots, benchmark data,
and real-world photo detection outputs generated by the Smart Canteen deep
learning pipeline.

Existing Result Files:
----------------------
1. `training_curves.png`
   - Training and validation loss convergence and accuracy curves across epochs.
2. `confusion_matrix_mobilenetv3-large.png`
   - Normalized confusion matrix across all 14 classes on the 572-image held-out test split.
3. `gradcam_samples.png`
   - Grid of Grad-CAM activation heatmaps explaining convolutional feature attention.
4. `misclassified_examples.png`
   - Visual breakdown of edge-case test samples with ground truth vs predicted classes.
5. `chai_samosa_success.png`
   - Successful multi-item detection identifying Samosa x1 + Chai x1 on a canteen tray.
6. `annotated_samosa_chai_01.jpg`
   - Real-world evaluation photo showing bounding box detections and confidence scores.
7. `debug_samosa_chai_01.jpg`
   - Full candidate proposal inspection view showing all proposals, status, and reject reasons.
8. `model_comparison.csv`
   - Tabular benchmark metrics comparing Baseline CNN, MobileNetV3-Large, and EfficientNet-B0.
9. `README.txt`
   - This manifest document.
================================================================================
